ASA Firewall Lab

How a Cisco ASA 5505 decides what to allow — security levels, the default rules, stateful inspection, and using an ACL to make exceptions. Read the reference, then work through the scenarios; each explains the reasoning.

Security levels

Every ASA interface has a security level from 0–100. The number says how trusted the network behind it is.

100
Insideyour LAN — most trusted
50
DMZpublic-facing servers
0
Outsidethe internet — least trusted

The default rules

Higher → lower is allowed. Traffic starting on a more-trusted interface can reach a less-trusted one (Inside → Outside, Inside → DMZ, DMZ → Outside) with no rule needed.
Lower → higher is denied. A new connection from a less-trusted interface to a more-trusted one is blocked by default (Outside → Inside, Outside → DMZ, DMZ → Inside).
Stateful inspection. The ASA remembers connections it allowed out, so the reply traffic is let back in automatically — you don't write a rule for return traffic.
An ACL makes the exceptions. To allow a specific lower→higher flow (e.g. the internet reaching a DMZ web server), you add an access-list permit and apply it to that interface:
access-list OUTSIDE_IN permit tcp any host 203.0.113.10 eq 443
access-group OUTSIDE_IN in interface outside
