Command Prompt Lab

The Windows network tools every technician reaches for — ipconfig, ping, tracert, nslookup, netstat, arp, whois and more — in a safe, simulated Command Prompt. Explore them freely, then use them to solve a real-world fault on the practice PC. Nothing here touches a real network.

Type a command and press Enter. ↑/↓ recall history, Tab completes, Ctrl+C stops a running command. Try help.
