Python Data Analysis Lab

Analyse real data with pandas and draw graphs with matplotlib, running real Python in your browser. Explore and clean a CSV file, filter by name and date range, group and compare, graph trends, make it robust and secure, then practise the testing, design and evaluation skills that ESP Tasks 2, 3, 4a and 4b reward. Every exercise is checked by running your code. All organisations, people and data are fictional.
