Tera Term Console

A Tera Term-style serial console on the lab PC. Pick the Router or the Switch and configure it from scratch with the full IOS command set — ? help, Tab completion and all. The two devices are cabled together on Gi0/0/0 ↔ Gi1/0/1, so you can bring a link up and test it.

COM3 - Tera Term VT — R1

Modes
  • enable
  • configure terminal
  • interface g0/0/0 (router) / g1/0/1 (switch)
  • exit · end · Ctrl+Z

      
Basics
  • hostname R1
  • enable secret class
  • banner motd #…#
  • no ip domain-lookup

      
Router interface
  • ip address 10.0.0.1 255.255.255.252
  • no shutdown
  • show ip interface brief

      
Switch / VLANs
  • vlan 10 → name STAFF
  • interface g1/0/2 → switchport mode access → switchport access vlan 10
  • interface vlan 1 → ip address …
  • show vlan brief

      
Save / verify
  • copy running-config startup-config
  • show running-config
  • reload · show version
