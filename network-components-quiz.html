Network Components Quiz

Each card shows a network topology symbol. Choose the component's name from the list, then drag the matching definition onto the card. On a tablet or touchscreen, tap a definition and then tap the card's box. Press Check answers when every card is complete.

Definitions — drag each one onto the right symbol. Drag a placed definition back here (or click it) to remove it.

Revise all twelve components before you try the quiz. The layer shows where each device mainly works in the OSI model.
