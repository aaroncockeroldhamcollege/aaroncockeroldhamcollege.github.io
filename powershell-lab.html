PowerShell Lab

Windows PowerShell for IT support and systems administration — discover commands, work with objects in the pipeline, manage files, services and processes, check the network, write your first script and look after users in Active Directory. It all runs on a simulated server, OAK-DC01, at the fictional Oakfield Physiotherapy Clinic, so nothing you type can break anything real.

Click in the PowerShell window (it opens in Windows Terminal) and type a command, then press Enter. Not sure where to start? Try Get-Help or Get-Command -Noun Service.
Tab completes cmdlets, parameters and paths (press again to cycle) · ↑↓ history · Ctrl+C stops a command · Esc clears the line · the ⌨️ button in the header swaps the dark terminal for a high-contrast white one.
