ESP Task 2: Test, Fix and Retest Lab

Practise the defect-finding task the way examiners want to see it: plan tests from the requirements first, run them, record the actual results, find and fix each defect, then retest after every fix and finish with a regression test. Choose a faulty network (Digital Infrastructure) or a network with security weaknesses (Cyber Security). Every organisation and system here is fictional - original practice material, not the live assessment.
