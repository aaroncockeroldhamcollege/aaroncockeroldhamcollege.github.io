Linux Command Line Lab

Linux fundamentals for IT support and networking, on a simulated Ubuntu server. Move around the file system, edit files in nano, set permissions, manage users, services and packages, read the logs and give the server a static IP. Everything happens in the browser, so you can't break anything.

The Linux file system

Everything lives under one tree that starts at / (the root). There are no drive letters.

/The root of the whole tree. /home/studentYour home folder, shown as ~ in the prompt. Your own files go here. /rootThe root user's home folder (not the same as /). /etcSystem-wide configuration: users (passwd, group, shadow), hosts, netplan/, apache2/. /var/logLog files: syslog, auth.log (logins and sudo), apache2/. /var/www/htmlApache's web root (after Apache is installed). /tmpTemporary files that anyone can write. Cleared at reboot. /usr/binPrograms (commands) such as ls, grep and nano.
Absolute vs relative paths. /var/log/syslog starts at the root and works from anywhere. Documents/notes.txt starts from where you are now (pwd). .. is the folder above; . is the current folder.

On a directory, r lets you list it, w lets you create and delete files in it, and x lets you cd into it.

Permissions as numbers — the chmod helper

Each group of three is added up: r = 4, w = 2, x = 1. So rwx = 7, r-x = 5, rw- = 6, r-- = 4. Tick the boxes or type a mode.

ModeStringTypical use
755rwxr-xr-xScripts, programs and folders everyone may use
644rw-r--r--Normal files, e.g. web pages
600rw-------Private files: keys, passwords, notes
700rwx------Private folders or scripts
775rwxrwxr-xShared folders that a team (group) can write to
Symbolic form: chmod u+x run.sh (add execute for the owner), chmod go-w file (take write away from group and others), chmod a=r file (everyone read-only).

sudo, root and users

Normal users can't change the system. sudo runs one command as root (the all-powerful administrator) after you type your own password. Only members of the sudo group are allowed; anyone else gets “… is not in the sudoers file. This incident will be reported.”

Least privilege: work as a normal user and use sudo only for the commands that need it. sudo -i gives a root shell (the prompt changes to #). Type exit to leave it.

Pipes and redirection

cmd > fileSend the output to a file (overwrites it)
cmd >> fileAdd the output to the end of a file
cmd1 | cmd2Feed the output of cmd1 into cmd2
cmd1 && cmd2Run cmd2 only if cmd1 worked
2>/dev/nullThrow away the error messages
