Draw it in Visio

  1. Open Visio and choose Network → Basic Network Diagram.

  3. Show the office areas, label every device and cable, and label each subnet with its network address and gateway (from section 3).

3IP addressing scheme AC 2.3not checked yet

The client has been given the block . Split it into one subnet for each VLAN below. Every subnet must be big enough for the hosts needed, start on a correct boundary, stay inside the block and not overlap another subnet. Use the first usable address as the default gateway.

How to work out a subnet (worked example)

Example (not one of your answers): a subnet that needs 12 hosts, starting at 10.0.0.0.

  1. Find the smallest block where block size − 2 ≥ hosts needed: 8 − 2 = 6 (too small), 16 − 2 = 14 ✓.
  2. A block of 16 = 24, so 4 host bits and 32 − 4 = /28. Mask: 256 − 16 = 240 → 255.255.255.240.
  3. Network 10.0.0.0 · first usable 10.0.0.1 (the gateway) · last usable 10.0.0.14 · broadcast 10.0.0.15 · 14 usable hosts.
  4. The next subnet starts at 10.0.0.16. Tip: allocate the largest subnet first so every subnet lands on a boundary.

Prefix → block size: /24 = 256 · /25 = 128 · /26 = 64 · /27 = 32 · /28 = 16 · /29 = 8 · /30 = 4.
